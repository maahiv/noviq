# Noviq Electronics

Noviq is a modern electronics e-commerce web application built with React.js and Firebase REST APIs.

## Features

- User authentication
  - Sign Up
  - Login
  - Logout
  - Forgot Password
- Product browsing
- Product search
- Category filtering
- Product details
- Shopping cart
- Quantity management
- Checkout
- Cash on Delivery
- Order history
- Order tracking
- User profile
- Multiple saved addresses

## Categories

- Headphones
- Wireless Earbuds
- Speakers
- Charger & Cable
- Gaming Series
- Smart Watches
- Mobile
- Laptop

## Tech Stack

- React.js
- Vite
- JavaScript
- Firebase Authentication REST API
- Firebase Realtime Database REST API
- CSS
- Vercel
